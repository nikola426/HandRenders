# HandRenders

HandRenders выравнивает изображение товара по изображению-образцу. Программа
подгоняет размер и положение объекта, сохраняет размеры холста образца и
записывает результат в формате WebP. Подход подходит не только для автомобилей,
но и для других товаров, если на обоих изображениях показан один и тот же
объект с похожего ракурса.

## Пример

В репозитории проекта примером служат изображения автомобиля из папки
`Исходники`: образец, исходное изображение другого цвета и результат
обработки.

| Образец | Исходное изображение | Результат |
| --- | --- | --- |
| ![Чёрный автомобиль — образец](for_readme/1.webp) | ![Серый автомобиль до обработки](for_readme/123.png) | ![Серый автомобиль после выравнивания](for_readme/123.webp) |

Для этого примера размеры образца и результата составляют 696 × 339 пикселей.
Размер и положение объекта в результате берутся из маски объекта на образце.

## Как работает программа

1. Загружает образец и исходное изображение, учитывая ориентацию EXIF.
2. Определяет фон каждого изображения:
   - если фон прозрачен, использует альфа-канал;
   - если изображение непрозрачное, оценивает цвет фона по краям кадра и
     удаляет связные с краями области похожего цвета.
3. Находит прямоугольные границы объекта по маске видимых пикселей.
4. Масштабирует объект исходного изображения до размеров объекта на образце и
   размещает его в тех же координатах.
5. Сохраняет результат в формате WebP с размерами холста образца.

Выделение сплошного фона является эвристическим. Наилучший результат
получается, когда фон однородный, занимает края изображения, а объект не
касается краёв. Сложный, неоднородный фон может быть выделен неточно.
Изображения товара должны показывать один и тот же объект примерно с того же
ракурса: программа подгоняет масштаб и расположение, но не меняет ракурс,
форму или освещение.

## Требования

- Python 3.10 или новее.
- Pillow 10.0 или новее.

Установите зависимость из корневой папки проекта:

```bash
python -m pip install -r requirements.txt
```

## Быстрый запуск

По умолчанию программа использует `Исходники/1.webp` как образец, ищет ровно
одно другое изображение поддерживаемого формата в папке `Исходники` и сохраняет
результат в `Результат/<имя исходного файла>.webp`.

```bash
python main.py
```

Если в папке образца не найдено ровно одно другое изображение, программа
сообщит об этом. Укажите исходный файл явно или уберите из папки лишние
изображения.

## Запуск с аргументами

Можно явно указать образец, исходное изображение и путь результата:

```bash
python main.py \
  --reference "Исходники/1.webp" \
  --source "Исходники/123.png" \
  --output "Результат/123.webp"
```

Доступные параметры:

| Параметр | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `--reference` | Путь к изображению-образцу | `Исходники/1.webp` |
| `--source` | Путь к изображению товара для обработки | Автоматический поиск одного изображения рядом с образцом |
| `--output` | Путь и имя выходного файла | `Результат/<имя исходника>.webp` |

Поддерживаемые входные расширения: BMP, JPEG, PNG, TIFF и WebP. Выход всегда
сохраняется в формате WebP.

После успешной обработки программа ждёт нажатия любой клавиши в интерактивном
терминале. Если стандартный ввод перенаправлен, для выхода нужно нажать Enter.
